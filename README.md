# Yekk

A marketing site for Yekk, a concept for "AI employees" that take routine work off small
business owners. Static HTML and Tailwind, with a documented design system.

Pages: `index.html` (landing), `how-it-works.html`, `use-cases.html`, and
`schedule-a-call.html`.

`DESIGN.md` sets out the design system: a quiet, editorial "Digital Curator" look, built
on tonal-nesting surfaces, glassmorphism, and a Manrope and Inter type pairing.

Open `index.html` in a browser.
